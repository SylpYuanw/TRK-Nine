## 发布流程

1. 编译:`dotnet msbuild Source\ClassLibrary1\ClassLibrary1.csproj /t:Rebuild /p:Configuration=Release`,输出即 MOD 的 `Assemblies/ClassLibrary1.dll`。
2. 同步:工作区 MOD 本体文件 → 仓库 `鼠鼠收尾人们目前已到245679协会/`;工作区 `Source/` → 仓库 `Source/`。
3. 推送:`git add -A` → `git commit -m "<变更说明>"` → `git push origin main`(凭据由 Windows credential manager 保存,可直接推送);提交信息按下方规范写。
4. 提交推送前无需向用户确认仓库地址与目录对应关系;仅在推送失败或改动范围超出本项目时询问。

## 提交信息规范

- 变更记录写在 git commit message 里,不写进 README;README 是要上传的公开文件,只写项目说明与仓库结构。
- 提交信息仅使用中文,不再附英文翻译。
- 更新条目每条独占一行,以 `-` 开头,换行后继续下一条,格式如下:
  `-修复Seven套装弱点分析可由远程攻击触发`
  `-同步更新Seven套装描述`
- 更新条目之后列出 `关联文件:`，包含实际变更的源码、程序集等文件。
- 提交信息列出实际变更内容,不写本机路径、编译命令、同步规则、推送步骤。
