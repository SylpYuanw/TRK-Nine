# 死之弓瞄准特效：现象、试验与文件指纹（2026-09-29）

## 一、结论（均附证据）

1. **Mote 的绘制通路每次提交一块 plane10 四边形。**
   证据：`Verse/Graphic_Mote.cs:DrawMote` → `Graphics.DrawMesh(MeshPool.plane10, matrix, material, layer, null, 0)`；`Verse/MeshPool.cs:70` → `plane10 = MeshMakerPlanes.NewPlaneMesh(1f)`。
   推论依据：该绘制调用不含几何裁剪，单个像素是否出现在画面中由材质片元输出的 alpha 决定（材质为 `Blend SrcAlpha OneMinusSrcAlpha`）。

2. **本 MOD 三层瞄准特效全部走该通路，且绘制变换每 tick 由瞄准角重算。**
   证据：`Source/ClassLibrary1/Weapon/BowOfDeath/Mote_DeathBowAimVfx.cs` 中 `Mote_DeathBowAimAlignedVfx.RotationAt/OffsetAt` 与 `Mote_DeathBowAimVfxBase.TimeInterval`；`Verse/Mote.cs` 的 `exactRotation/exactPosition`。

3. **`Textures/VFX/Bow_of_Death_Aim_Vfx.png` 的形体不是矩形。**
   数据（numpy 统计，阈值 `alpha>0.12`）：bbox x[65..1174] y[112..1112]（占贴图 89%×80%），bbox 内填充率 62.8%，逐行宽度采样 153 / 465 / 621 / 686 / 1020 / 761 / 958 / 786。

4. **`Material.GetTexture()` 在未显式绑定过时返回 Shader 默认贴图，而不是 null。**
   证据：Unity 渲染环境复现——`_StartTex` 不绑定时（默认值 `white`），扩散层整块 4×4 画布被默认贴图铺满并逐帧变化；对应代码 `Mote_DeathBowAimChargeVfx.ApplyStartTexture()` 的旧判断 `if (material.GetTexture("_StartTex") != null) return;`。

5. **预览窗口的属性契约是"XML 参数 ∪ 内部属性"，内部属性按层判定。**
   证据：窗口报错原文 `读取失败：Trk/BowOfDeathAimWind 属性与调参窗口不一致。缺少：_StartTex；额外：`，成因是 `_StartTex` 被写入所有层共用的内部属性集合，而主体层 Shader 不含该属性。

## 四、本轮使用的验证手段（可复现）

- 文件级：`Get-FileHash -Algorithm SHA256` 与 `git show <commit>:<path>` 比对。
- 资源级：UnityPy 解包读 Shader 属性表；Unity `BuildPipeline.BuildAssetBundles` + `AssetBundle.LoadFromFile` 复核包内资源路径与 Shader 名称。
- 渲染级：Unity 批量渲染（`Graphics.Blit`）后按像素统计 alpha 覆盖率、质心、边缘分布。
- 游戏级：GABS 桥接（`take_screenshot`、`get_cell_info`、`save_game`、`load_game_ready`、`step_game_ticks`）用于读取实机状态与逐格对象。
- 边界说明：以上均为渲染与文件数据；游戏内观感验收结果由用户给出。
